# R2.3 Maple DMA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a truthful software-triggered single-entry Maple DMA path to the Dreamcast reference boot runtime, ending in the documented no-device response and Maple-DMA-complete System ASIC interrupt.

**Architecture:** Extend the existing `DreamcastMaple` MMIO device into a synchronous DMA engine that reads/writes `DreamcastExecutableMemory` and reports completion through `DreamcastSystemAsic`. Support only one final descriptor and no attached peripheral endpoint; all unsupported modes fail deterministically instead of simulating behavior.

**Tech Stack:** C++20, existing `Result<T>` error model, Dreamcast reference memory/bus, System ASIC interrupt model, CMake/CTest, GitHub Actions Linux + Windows/MSVC.

**Spec:** `docs/superpowers/specs/2026-09-02-maple-dma-design.md`

## Global Constraints

- Keep shipping distribution as one executable: `JOJO-Recompiled.exe`.
- Do not add copyrighted game data, commercial fingerprints, or guessed revision data.
- R2.2 remains `blocked-external-evidence` without legally supplied media.
- R2.3 remains `implemented-unverified`; generic DMA tests do not prove commercial-game compatibility.
- Support only software-triggered, single-final-entry Maple DMA in this increment.
- No controller, VMU, hardware/VBlank trigger, multi-entry queue, or cycle-accurate timing in this increment.

- [ ] **Step 1: Write the failing integration test**

Add a test that preloads a valid one-entry Maple command table into main RAM using SH-4 stores before writing `MDST=1`. The descriptor layout is:

```text
MDSTAR + 0x00: 0x80000000  # final entry, port 0, zero payload words
MDSTAR + 0x04: receive address in main RAM
MDSTAR + 0x08: 0x01200000  # Device Request frame header, destination 0x20, source 0x00
```

The boot program must configure `MDSTAR`, set `MDEN=1`, write `MDST=1`, then load the receive word. Assert:

```cpp
CHECK(run);
CHECK(run.value.stop_reason == jojo::DreamcastBootStopReason::end_of_program);
CHECK(!run.value.bus_fault.has_value());
CHECK(run.value.state.r[expected_register] == 0xFFFFFFFFu);
```

### Task 2: Maple DMA engine and register semantics

**Files:**
- Modify: `src/core/dreamcast_maple.h`
- Modify: `src/core/dreamcast_boot_runner.cpp`

**Interfaces:**
- Consumes: `DreamcastExecutableMemory`, `read_dreamcast_u32`, `write_dreamcast_u32`, and `DreamcastSystemAsic::raise_normal(std::uint32_t)`.
- Produces: `DreamcastMaple(DreamcastExecutableMemory&, DreamcastSystemAsic&)`, readable/writable `SB_MDST`, synchronous single-entry DMA execution, and normal event bit 12 on successful completion.

- [ ] **Step 1: Give Maple access to memory and System ASIC**

Change construction to:

```cpp
DreamcastMaple(DreamcastExecutableMemory& memory,
               DreamcastSystemAsic& system_asic) noexcept;
```

Store non-owning pointers to both dependencies. Update the boot runner from `DreamcastMaple maple;` to:

```cpp
DreamcastMaple maple(result.memory, system_asic);
```

- [ ] **Step 2: Add `MDST` read/write state**

Define `kMdst = kMapleBase + 0x18u` and `mdst_`. Reads of any byte within `MDST` return the current 32-bit state. `MDST=0` writes are accepted as no-ops; only bit 0 may request start.

- [ ] **Step 3: Implement start preconditions**

Before touching command/receive memory, reject start when:

```cpp
(mden_ & 1u) == 0u
(mdtsel_ & 1u) != 0u
(mdstar_ & 31u) != 0u
```

Also use `read_dreamcast_u32` to prove the descriptor span is mapped; propagate its `Result` error detail through a Maple-specific failure.

- [ ] **Step 4: Parse and validate one descriptor**

Read control, receive address, and frame header at `mdstar_ + {0,4,8}`. Require:

```cpp
(control & 0x80000000u) != 0u
(control & 0x7FFCFF00u) == 0u
((control >> 16u) & 0x3u) <= 3u
```

Set `payload_words = control & 0xFFu` and read every declared payload word at `mdstar_ + 12u + i * 4u` solely to validate the full span. Check 32-bit address arithmetic before each addition.

- [ ] **Step 5: Validate and write no-device response**

Require the receive address to be 32-bit aligned, then call:

```cpp
write_dreamcast_u32(*memory_, receive_address, 0xFFFFFFFFu)
```

Do not create or dispatch a controller endpoint.

- [ ] **Step 6: Complete DMA and raise interrupt**

Set `mdst_ = 1u` only while executing. On successful completion set `mdst_ = 0u` and call:

```cpp
system_asic_->raise_normal(1u << 12u);
```

On every failure path restore `mdst_ = 0u` before returning failure and do not raise the interrupt.

- [ ] **Step 7: Run the boot-runner regression**

Push implementation and require the exact RED integration test to turn GREEN.

### Task 3: Direct Maple validation tests

**Files:**
- Create: `tests/test_dreamcast_maple.cpp`
- Modify: `CMakeLists.txt`

**Interfaces:**
- Consumes: `DreamcastMaple`, `DreamcastExecutableMemory`, `DreamcastSystemAsic`, and `DreamcastMmioDevice` byte reads/writes.
- Produces: focused regression coverage independent of SH-4 instruction encoding.

- [ ] **Step 1: Add test helpers for 32-bit MMIO writes/reads**

Use four ordered `write8`/`read8` calls so tests exercise the public MMIO interface rather than private state.

- [ ] **Step 2: Test successful single-entry DMA**

Create a 16 MiB main RAM memory, place the descriptor/frame at `0x0C000100`, set receive buffer `0x0C000200`, configure MDSTAR/MDEN, then write MDST=1. Assert receive word becomes `0xFFFFFFFF` and MDST reads zero afterward.

- [ ] **Step 3: Test disabled DMA rejection**

With MDEN zero, write MDST=1 and assert failure, unchanged receive word, and MDST idle.

- [ ] **Step 4: Test hardware-trigger rejection**

Set MDTSEL=1 and MDEN=1, then write MDST=1. Assert failure and no receive-memory modification.

- [ ] **Step 5: Test malformed descriptor rejection**

Use a control word without bit 31 set. Assert failure, MDST idle, and no receive-memory modification.

- [ ] **Step 6: Test invalid receive address rejection**

Use an unmapped or misaligned receive address. Assert failure and MDST idle.

- [ ] **Step 7: Test completion interrupt bit**

After successful DMA, read System ASIC normal status bytes at `0x005F6900..03` and reconstruct the word. Assert `(status & (1u << 12u)) != 0u`.

- [ ] **Step 8: Register test target in CMake**

Add:

```cmake

target_link_libraries(jojo_dreamcast_maple_tests PRIVATE jojo_core)
add_test(NAME jojo_dreamcast_maple_tests COMMAND jojo_dreamcast_maple_tests)
```

- [ ] **Step 9: Run full test suite**

Require all portable tests to pass, including the new Maple target.
